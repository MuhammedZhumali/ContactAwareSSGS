This supplement belongs to the AITU revision of When Future Contacts Improve Satellite Key and Security Association Management. It documents a new bounded campaign and preserves the prior final-v2 campaign separately. Full per-cell tables are provided as CSV and JSON; raw events, checkpoints, observations, plans, candidate portfolios, invocations and process logs are in the reproduction package. Rounded values here do not replace the machine-readable precision.

The prior campaign has 108 attempts,93 FINISHED and 15 PROCESS\_TIMEOUT. First-revision execution comprises 110 full-controller attempts: 105 FINISHED and 5 SEARCH\_INCOMPLETE. Twelve additional paired-root diagnostics have 11 exact COMPLETE and 1 exact INCOMPLETE. Six reused logical cells have explicit origins: four prepared exact X01 cells in the synthetic family and two autonomous practical X/CANONICAL/5000-node cells in the budget series. No registered new attempt is missing.

The frozen final-v2 JAR and its SHA256 are identified in the reproduction manifest. A separate harness exports matched initial states. A separate root-only planner overlay records incumbent changes; normal controllers never load it. Focused validation matched the frozen planner's complete plan, score, first action, status and node count on a fixed-node example. This is a bounded instrumentation check, not universal zero-overhead equivalence.

\section*{Disclosure model and metric definitions}
E=2026-10-12T00:14:59.990386963Z. Compromise E$-$40/E$-$20/E$-$5, delay 0/2/20 seconds, same active-pair target rule and geometry for all policies. All 36 runs FINISHED, all 36 targets DISCLOSED, all 36 independent-frame milestones observed. No NO\_TARGET or censored values occurred in this grid. The measurement implementation still represents missing events explicitly and does not extrapolate incomplete runs.

Each milestone's origin is actual ground notice. Spacecraft notice is confirmed revocation receipt. Independent pair requires both directional keys to be agreed active, valid, and outside the disclosed set. Independent SA requires those materials bound to an open admissible context. Independent frame requires complete actual delivery. Earlier readiness is marked already\_ready when applicable, never imputed from a missing event. Full delay is compromise-to-ground plus ground-to-frame, using actual timestamps. Subsequent expiration and closure delimit readiness; the first milestone is not continuous readiness.

Confidential delivered bytes count complete delivered frames whose keys are not disclosed during the modeled run. Exposure instead integrates emitted byte ranges, including incomplete frames, split before and after compromise. Retrospective disclosure can therefore invalidate confidentiality of earlier deliveries. These metrics do not measure attack probability or implementation-level cryptographic security. Directional replacements are modeled independent, and the management channel remains protected.

\subsection*{Reconstructing the method}
CONTINUE\_WAIT prepends (group, until) to the canonical tuple: group is CONTINUE=0, WAIT=1, all service operations=2. Thus until is compared before operation kind even within the service group. This complete order differs from tree visitation: SERVICE\_FIRST visits CONTINUE, SWITCH, INSTALL, OPEN, REUSE, WAIT, PREPARE, with canonical secondary ordering. Seeds and retained plans are not injected as DFS incumbents.

Practical controller pseudocode\newline{}
1. At an event, construct the permitted observation and admissible actions.\newline{}
2. Build a terminal seed; check, replay and extend any matching retained suffix from the same root.\newline{}
3. Run bounded unrestricted search; propagate global stops.\newline{}
4. Compare feasible terminal candidates by the five criteria, then the full-plan rule.\newline{}
5. If a plan exists, save its suffix with the predicted first-action child.\newline{}
6. In measured-delay mode, advance committed work/events during computation, rebuild admissibility, and recheck the chosen intent; discard stale or late decisions.\newline{}
7. Execute only the admissible first action and repeat. Mandatory incident response takes precedence.

The seed waits while a frame or operation is already in flight. With complete-frame demand in the current contact, it prefers CONTINUE, OPEN, REUSE, SWITCH, INSTALL, PREPARE, subject to ordinary feasibility and an optimistic remaining-chain-plus-one-frame fit. Between contacts, it inspects the first eligible visible demand and prepares only an UNKEYED context at or after its just-in-time preparation boundary. Otherwise it takes the earliest generated WAIT. Retention replays from the new root, checking state, progress, costs, counters and issued IDs; it does not reuse the previous score. If no terminal candidate exists, an admissible local fallback is used. Supplement gives the full seed filters and source tie handling.

Seed service-fit remainder is zero for CONTINUE, one frame for OPEN/REUSE, OPEN plus one frame for SWITCH, SWITCH+OPEN+one frame for INSTALL, and INSTALL+SWITCH+OPEN+one frame for PREPARE. This filter requires action.until plus the remainder to fit in the contact and rejects uncertain contexts. Between contacts it stops at the first eligible visible full-frame demand even if that keyed context needs no PREPARE; it does not prepare a farther context instead. At a current contact without full-frame demand it waits. On exact equality of score and complete plan, the portfolio prefers SEARCH; otherwise an identical seed precedes an identical retained candidate. This source choice is not a sixth objective.
