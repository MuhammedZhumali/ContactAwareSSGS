# Протокол проверки допустимости фрагмента

Дата задания: 2026-10-24. Статус: **NO_ELIGIBLE_FRAGMENT**.
Это протокол выполненной проверки выбора, не предрегистрация запущенной серии.

Задание разрешает ровно один ранее не исследованный отдельный трёхконтактный
фрагмент A–B–A из существующих 46 последовательных контактов, без удаления окон.
Если подходящей тройки нет, требуется зафиксировать отсутствие и предложить
минимальный альтернативный вариант без запуска другой серии. Выполнена эта ветвь.

Последовательность проверки:

1. Сверить schedule.json и selected-contacts.json, количество и временной порядок.
2. Перечислить все соседние тройки i, i+1, i+2 и проверить A=C, A≠B.
3. Сверить прежние отдельные тройки по manifest/protocol SE2 и историческим
   FINISHED-строкам, дополнительно прочитать протоколы SE1/SE2.2.
4. Если новых троек нет, остановиться до инициализации сценариев, регистрации,
   watchdog, сборки и запуска политик. Перечислить кратчайший другой непрерывный
   блок возврата; при равной длине выбрать первый по времени, без его исполнения.
5. Сохранить CSV, JSON, read-only подтверждение, хеши и компактный архив.

Данные CP5400/light, H=1/2, CANONICAL/CONTINUE_WAIT, none/late-detected,
SERVICE_FIRST/reuse ON/V2, бюджеты 2M/30s, 60s, 90s остаются **исходным запросом**.
На другом фрагменте они не применялись. Ни новый профиль, ни альтернативный H=3
не вводились. Нет результатов восстановления или затрат, которые можно сравнить.

Владение и статус задач:

- Основной агент: выбор/сверка и сохранение свидетельств — завершено.
- Один read-only подагент: независимая проверка тройки и прежнего использования — завершено.
- Регистрация, сборка, watchdog, восемь исполнений, аудит исполнения — не начаты из-за отсутствия входа.

Воспроизводимые команды из корня (scan отказывается заменять существующий каталог,
package отказывается заменять архив):

```powershell
python -X utf8 scripts/check_iss_transfer_selection.py scan
python -X utf8 scripts/check_iss_transfer_selection.py package
```

Скрипт выполняет только чтение источников, проверки и запись новых свидетельств.
Сохранённые статусы прошлых политик используются лишь для исключения ранее
изученного фрагмента. Выбор не зависит от величины выигрыша или проигрыша Multi.
